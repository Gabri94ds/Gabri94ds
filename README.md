ATENÇÃO:

no mesmo repositório do perfil.

PASSO 1

Gabri94ds

O README.md deste repositório aparecerá no seu perfil.

PASSO 2
Crie o arquivo:

.github/workflows/snake.yml

PASSO 3
Copie o YAML abaixo para snake.yml,
sem incluir os marcadores deste comentário HTML.

------------------------------------------------------------
INÍCIO DO ARQUIVO snake.yml
------------------------------------------------------------

name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 3 * * *"

  workflow_dispatch:

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Generate Snake SVG
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: Gabri94ds
          outputs: |
            dist/github-contribution-grid-snake.svg?color_snake=%2338BDF8&color_dots=%23020617,%230C4A6E,%230369A1,%230284C7,%2338BDF8
            dist/github-contribution-grid-snake-dark.svg?color_snake=%2338BDF8&color_dots=%23020617,%230C4A6E,%230369A1,%230284C7,%2338BDF8

      - name: Publish Snake SVG
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

------------------------------------------------------------
FIM DO ARQUIVO snake.yml
------------------------------------------------------------

PASSO 4
No GitHub, acesse:

Settings > Actions > General

Em Workflow permissions, habilite:

Read and write permissions

Essa permissão permite publicar os SVGs na branch output.

PASSO 5
Acesse:

Actions > Generate Contribution Snake > Run workflow

Execute manualmente o workflow pela primeira vez.

PASSO 6
Após a execução bem-sucedida, a branch "output"
conterá os SVGs da animação.

O README já aponta para esses arquivos.

A atualização será automática, aproximadamente
uma vez ao dia, conforme o agendamento do GitHub.
